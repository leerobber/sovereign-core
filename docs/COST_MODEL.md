# SovereignNation Cost Model

## Infrastructure Costs (Monthly)

| Service | Cost | Notes |
|---------|------|-------|
| VPS / cloud hosting | $20–40 | DigitalOcean droplet or Hetzner |
| Domain (.com) | $1/mo | ~$12/year |
| Stripe fees | 2.9% + $0.30/txn | ~$1.14 per $29 sub |
| Ollama inference (local) | $0 | Runs on your machine |
| RunPod training (after funded) | ~$2–5/run | A5000 @ ~$0.50/hr, 4–6hr run |
| HuggingFace (free tier) | $0 | Public repos + datasets |
| Kaggle training | $0 | 30hr/week T4 GPU |
| Email (Resend/SendGrid) | $0–20 | Free tier covers early users |

**Total monthly cost (pre-funding)**: ~$25–60/month

## What To Do With First Revenue

1. $0–500 MRR: Cover hosting, reinvest in marketing content
2. $500–1,500 MRR: Buy RunPod credits for continuous agent training
3. $1,500–5,000 MRR: Hire part-time VA for support
4. $5,000+ MRR: Full infrastructure upgrade, mobile app development
